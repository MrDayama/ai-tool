| 項目 | 内容 |

| **投稿者** | 松濤Vimmer (@shotovim) |
| **投稿日** | 2026-06-26 |
| **いいね** | 104 |
| **RT** | 8 |
| **閲覧数** | 8,295 |
| **URL** | [ツイートを見る](https://x.com/shotovim/status/2070517620403757440) |

### 概要
**Obsidian Bases**の解説。Vault内のノートをデータベースのように扱えるコアプラグイン。

### 核心ポイント
- **Basesとは**：Vault内のノートをDB的に扱えるコアプラグイン
- **Notionとの違い**：ファイルの保存場所は一切変わらない（最大の特徴）
  - Notionだと → DBに移動するとDB内に閉じ込められる
  - Basesは → あくまで「ビュー」（フィルター）で抽出するだけ
  - **元のフォルダの独立性は保たれたまま**
- **作り方**：
  - リボンのベース作成アイコン
  - コマンドパレットから `Bases: Create new base（ベース：新規ベースを作成）`
  - 最初はVault内の全ファイルが対象 → フィルターで絞り込む必要あり
- イメージ：「データを見る角度を変える」

> [!IMPORTANT]
> 当Vaultのフォルダ構成（01_Imo等）を維持しつつ、Basesで横断的にノートを管理する運用が可能。導入検討推奨。

## 5. ObsidianでHTML iframe埋め込みテク 🖥️

| 項目 | 内容 |
|:---|:---|
| **投稿者** | 松濤Vimmer (@shotovim) |
| **投稿日** | 2026-05-21 |
| **いいね** | 313 |
| **RT** | 27 |
| **閲覧数** | 32,053 |
| **URL** | [ツイートを見る](https://x.com/shotovim/status/2057469209308004764) |

### 概要
マークダウンの書き心地を維持しながら、HTMLの読みやすさも共存させる**iframe埋め込みテクニック**。

### 核心ポイント
- **HTMLだけだと書きづらい**、Markdownだけだと表現力に限界
- 解決策：**ObsidianにHTMLをiframeで埋め込む**
- **運用方法**：
  - HTMLはiframeで埋め込み
  - 普段は**コールアウト内に収納**
  - 必要なときだけ展開して見られる
- **メリット**：
  - 場所を取らない
  - Markdown自体が汚染されない
  - マークダウンとHTMLの両方の良さを活用可能

> [!NOTE]
> 当Vaultでは既にこのテクニックを **Dashboard.md** と **Poker_Strategy_Embed.md** で実装済み！松濤Vimmer氏のこのツイートが元ネタ。
