# 🎨 ゲームUI調査プロジェクト — 画面スペース活用とUI改善報告書

> [!abstract] 概要
> 本ドキュメントは、「タイムボム Online」のブラウザ版における「背景が広い（余白スペースが活用しきれていない）」という課題を出発点として、ゲームUIにおける画面アスペクト比・余白の活用手法、他プロジェクトにも応用可能な調査フレームワーク、およびタイムボムにおける複数の具体的なUI改善案を整理したものです。

---

## 🔬 1. 汎用的なゲームUI調査・設計フレームワーク（他へ応用可能な手法）

Webアプリやゲームをデスクトップなどの大画面（16:9 や 21:9）で表示する際、コンテンツ（中央のウィンドウ）の左右に生まれる広大な余白（背景）をどうデザインするかは、ユーザー体験（UX）を決定づける重要な要素です。

他プロジェクトでも活用できる、アスペクト比とスペース利用の調査・設計フレームワークを定義します。

### 📊 スペース活用・分析マトリクス

| 区分 (アプローチ) | 主な目的 | メリット | デメリット | 応用先例 |
|:---|:---|:---|:---|:---|
| **① Ambient (環境的演出)** | 没入感の向上、雰囲気の強化 | ユーザーの視線誘導を邪魔せず、ゲーム世界観を広げる | 直接的な利便性はない | RPGの動く背景、パズルのテーマ壁紙 |
| **② Widget (補助的情報提供)** | メイン情報の分散、視覚的充実 | 未使用スペースにステータス、ログ、チャット等を常時展開 | 画面が煩雑（ノイズ）になるリスク | MMOの常時HUD、ポーカーの履歴 |
| **③ OS / Desktop (メタ構造化)** | 操作領域の拡張、遊び心の追加 | 背景そのものをデスクトップと見立ててミニアプリ等を置く | 開発コストが高め | シミュレーター系ゲーム、レトロOS風UI |
| **④ Expand (動的レイアウト拡張)** | 複数端末最適化 | 画面幅に応じてコンテンツ自体がグリッド数やカラム数を増やす | レスポンシブ設計の難易度向上 | Trello型ダッシュボード、カード一覧 |

## ⚙️ 2. タイムボム Online 現状分析と課題

現行の「タイムボム Online」は以下の構成となっています。
- **画面解像度**: 中央の `win98-window` が `max-width: 640px` (ロビーなど) または `max-width: 1040px` (ゲーム画面) に制限されています。
- **背景**: `:root` に設定された単色の背景（例: Win98テーマなら単色ティール `#008080`、サイバーなら濃紺 `#07090f`）に、薄いドットパターンが敷かれているのみです。
- **問題点**:
  - デスクトップPC（FHDや4K）などのアスペクト比 16:9 以上のディスプレイで開いた際、**左右および上下の余白（背景）の比率が非常に大きく、何も情報がないため寂しい印象を与える（「背景が広い」）**。
  - ゲームのチャットや履歴ログ、現在参加中のメンバー情報、仕様説明などが、すべて中央ウィンドウの狭い領域内に詰め込まれており、スペースの配分が不均衡である。

## 💡 3. UI/UX 改善案（複数アプローチ）

「背景が広い」という課題を解決するために、前述のフレームワークに基づいて4つの具体的な改善案を提案します。

---

### 💡 改善案A: 【Widget】レスポンシブ・サイドパネル・ドロワー（おすすめ）
中央のメインゲームウィンドウを邪魔せず、左右の広大な余白に「ゲームログ（履歴）」や「簡易チャット」「遊び方・ルール表示」をピン留めできるドッキングパネルを実装します。

```
+-------------------------------------------------------------------+
| [Win98 Taskbar]                                                   |
+-------------------------------------------------------------------+
|                     +----------------------+  +-----------------+ |
|                     |                      |  | 📖 クイックルール| |
|  +---------------+  |                      |  | 🚔 警察: 解除⚡  | |
|  | 📋 ゲーム履歴  |  |   💣 TIME BOMB       |  | 💣 ボマー: 爆発  | |
|  | - AがBをめくった |  |   [メインゲーム画面] |  +-----------------+ |
|  | - ⚡解除コード!  |  |                      |  +-----------------+ |
|  | - 第2ラウンド開始|  |                      |  | 🤖 Bot 設定/ログ| |
|  +---------------+  +----------------------+  +-----------------+ |
+-------------------------------------------------------------------+
```
*   **詳細**:
    *   画面幅が十分広い場合（例: `1200px` 以上）は、自動的に左右にフローティングウィンドウ風のウィジェット（ログ、ルールサマリー）を展開。
    *   モバイル端末などの狭い画面では自動的に非表示（または下部にドロワー化）にするレスポンシブ設計。
*   **期待効果**: ゲーム中「誰が誰をカットしたか」「前のラウンドで何が起きたか」が常に横に表示されるため、推理（正体隠匿）の利便性が飛躍的に向上します。

---

### 💡 改善案B: 【OS/Desktop】Win98「アクティブ・デスクトップ」化
背景のティールグリーン全体を「本物の仮想OSのデスクトップ」に見立て、デスクトップ上にアイコンやミニツールを配置します。

```
+-------------------------------------------------------------------+
|  [My Computer]                                                    |
|  [Minesweeper]      +----------------------+                      |
|                     |                      |                      |
|  [PDF Manual]       |   💣 TIME BOMB       |                      |
|                     |   [メインゲーム画面] |                      |
|                     |                      |                      |
|                     +----------------------+      [Trash Bin]     |
+-------------------------------------------------------------------+
| [❖ スタート]  [💣 タイムボム Online.exe]              ⏰ 16:15 PM  |
+-------------------------------------------------------------------+
```
*   **詳細**:
    *   デスクトップアイコンとして以下を配置（ダブルクリックで別ウィンドウが開く）：
        *   `マイ コンピュータ`（プレイヤープロフィール・戦績）
        *   `マニュアル.pdf`（仕様説明書をWin98のテキストエディタ風ウィンドウで開く）
        *   `マインスイーパ.exe`（待ち時間用の簡易マインスイーパゲーム）
    *   サイバーネオンテーマなら「グリッドとシステムモニタ」、8-Bitなら「ドット絵のマップ背景」など、テーマ毎に背景のコンテンツを切り替え。
*   **期待効果**: Win98のOSコンセプトがさらに際立ち、他プレイヤーが揃うまでの待ち時間を楽しませる体験（エンターテインメント性）を最大化します。

---

### 💡 改善案C: 【Ambient】テーマ連動ダイナミック・バックドロップ
ただの単色背景ではなく、テーマごとに動きのあるリッチなビジュアル背景を展開します。

*   **詳細**:
    *   **Windows 98**: 当時のスクリーンセーバー風のパイプアニメーションや、フライングWindowsロゴを背景に超軽量キャンバスで描画。
    *   **サイバーネオン**: Matrixコードの雨（デジタルフォール）や、明滅するサイバー回路ラインを背景に投影。
    *   **8-Bitレトロ**: レトロゲーム風に雲や星が左から右にゆっくりスクロールするパララックス（視差）アニメーション。
    *   **シンプルライト**: HSLのソフトグラデーションオーブがゆっくりと変形・漂うアンビエント背景。
*   **期待効果**: 「ただの余白」が「動くビジュアルアート」に昇華され、プレミアムなデザイン性（WOW効果）が向上します。

---

### 💡 改善案D: 【Expand】サークル状プレイヤーボード配置（アリーナスタイル）
現状の「上から縦に並ぶプレイヤーカード」を排し、大画面ではカードがテーブルを囲むようにサークル（円状）にダイナミックに配置されるポーカーテーブル風の「アリーナレイアウト」を採用します。

*   **詳細**:
    *   画面幅に応じて、グリッド配置から円形テーブル配置（テーブルトークRPGやポーカーのようなレイアウト）へ自動で切り替える。
    *   中央には「導線トラッカー」や「解除コード進捗」を3Dグラフィック風に大きく配置。
*   **期待効果**: 心理戦を行う対戦ゲームとしての雰囲気や、「皆でテーブルを囲んでいる」感覚が非常に強まります。

---

## 📅 4. 推奨するステップとロードマップ

1.  **Phase 1 (本調査ノート作成・合意)**: 本ドキュメントにて方向性を合意。
2.  **Phase 2 (改善案A＋Cの実装)**:
    *   大画面時に左右の余白へ「ゲーム履歴ログ（Widget）」および「クイックルール」を表示するサイドパネルの実装（改善案A）。
    *   テーマごとのアンビエント演出の強化（改善案C）。
3.  **Phase 3 (セキュリティ・不具合修正)**:
    *   プレイヤー名に対するXSSサニタイズ（エスケープ）の実装。
    *   ラウンド切り替え時のBot手番自動進行不具合の解消。

## 💫 5. アニメーション演出と視覚的フィードバック（マイクロインタラクション）

ゲームにおける「WOW効果」と操作時の快適さを極大化するため、以下の軽量かつ印象的なアニメーションとエフェクトを実装しました。

### 🎴 5.1 物理的な 3D カードフリップ
*   **仕組み**: `transform: rotateY(180deg)` と `backface-visibility: hidden`、および `perspective`（遠近感）をCSSで組み合わせることで、カードをめくった際のリアルな裏返り動作を表現。
*   **効果**: 平面的な表示切り替えに比べ、実際に「カードを裏返している」という手触り感・緊張感を与えます。

### 🎆 5.2 判定連動型パーティクルエフェクト
カードがめくられた瞬間の結果に応じて、キャンバス上に動的な火花や爆発を散らします。
*   **⚡ 解除コード (Success)**: カードの中心から緑色と金色の光の粒子が放射状に飛び散るスパーク演出。
*   **💣 爆弾 (Explode)**: 画面全体を震わせながら、赤い爆煙とオレンジ色の火の粉が大きく広がる爆発エフェクト。
*   **💤 し〜ん (Safe)**: 煙のようなパーティクルがふわりと広がる静かな演出。

### 🖱️ 5.3 直感的なホバー＆マイクロアクション
*   **選択対象の浮き上がり**: ニッパーを保持しており、カードを選択（カット）できる状態のときのみ、他プレイヤーのカードにカーソルを合わせると `translateY(-6px)` 浮き上がるモーションを追加。
*   **Win98デスクトップホバー**: クラシックテーマ時の背景アイコンは、ホバー時に実機のWindows 98のように文字背景色が反転（青色）し、選択されたことを示します。

### ⚡ 5.4 GPU加速によるパフォーマンス最適化
アニメーションの描画負荷でゲーム動作が重くならないよう、動的背景（ネオングリッド、スクロール星空）には `will-change` や `transform: translate3d` を適用し、ブラウザのGPU支援を有効化。CPU使用率を極限まで低く保ちながら高フレームレートを両立させています。
