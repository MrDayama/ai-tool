# 全ツイート調査ノート

Vault内の `source` にツイートURLを含むリサーチノートを一覧するBasesビュー。

> [!NOTE]
> フィルタ条件: `source` に `x.com` または `twitter.com` を含む

## 手動フィルタ設定手順
1. コマンドパレット → `Bases: Create new base`
2. フィルタに `source contains x.com` を設定
3. 表示列: name, tags, date, source, status
