Archie — スターティングハンド一覧（参考）

注：この一覧は Overview / strategy に基づくスターティングハンドの具体例集。ハンドは5枚の初期配牌（ドリーハンド）を想定。スートの組合せは代表例のみ記載（同スート=suited, 異スート=mixed）。実戦では位置・アクション・マルチウェイ等を考慮すること。

使い方

  • 各カテゴリは EV 観点での優先度（S > A > B > C）
  • "スクープポテンシャル" が高いハンドは S/A に分類
  • 以下は具体ハンド例。スートは代表例に留め、同等の別スートも当てはまる。

S — 最優先（超強力、スクープ期待値が高い）

説明具体例（代表）
Wheel・ほぼ完成ロー＋ハイの両狙い（Aを含む4toWheel, 4toWheel+flush）A♠ 2♠ 3♠ 4♠ 9♣（4toWheel + 1枚でWheel/Flush）
Wheelに非常に近い4枚＋ハート等スートでのフラッシュポテンシャルA♥ 2♥ 3♥ 4♥ K♣（suited 4-to-wheel）
Aを含む4枚ロー＋ミドルカード（複合ドロー）A♣ 2♦ 3♠ 4♣ 5♦（ほぼWheel完成）
ローハンドとハイハンド両方の改善余地がある構成A♦ 2♦ 3♣ 9♦ 5♦（ロー有望＋フラッシュ期待）
ストレートフラッシュに直結する4枚（スート揃い）9♠ T♠ J♠ Q♠ 2♦（4-to-straight-flush）
  • 代表例を拡張すると、A234 + any（A234x）や A2x3x4x の組合せはすべてS帯。
  • 例：A♠2♠3♠4♣5♣ / A♥2♥3♥4♥6♠ / A♦2♣3♦4♦9♥ など

A — 高EV（ロー主導／ハイ主導の強力ハンド）

説明具体例
強力なトリップス（Trips）やフラッシュ・ロー完成に近いハンドK♠ K♦ K♣ 4♥ 9♦（Trips K）
Aを含む3枚以上のローテンパイ（3-to-low 〜 4-to-low）A♣ 2♠ 3♦ 7♣ 8♦（3〜4to-low）
強いハイフラッシュドロー（4-to-flush with A or high cards）A♠ K♠ Q♠ J♣ 2♦（4-to-flush）
Wheel候補＋高ランクカードの混合（A含むがややブロッカーあり）A♣ 2♦ 4♠ 5♣ 9♠
  • 具体例拡張：AAKxx（例：A♠ A♥ K♣ 4♦ 9♣）はハイで強く、A含むロー系と比べても堅い。
  • 例：A♠ 2♦ 3♣ 6♠ 9♦ / K♠ K♥ 3♦ 4♣ 7♣ / Q♠ J♠ T♦ 9♠ 2♣

B — 中〜低リスク（条件付きでプレイ）

説明具体例
Aを含まないロードロー（逆ドミネイトリスクあり）2♠ 4♦ 5♣ 7♥ J♠（2–4–5–7–J）
マージナルなハイペア（9のペア等） — ポジション限定で可9♠ 9♣ 2♦ 5♥ J♠（9のペア）
スーテッド2枚＋低ランクのロー候補（投機的）4♠ 5♠ 8♦ J♣ Q♥（suited 4-5 のような投機）
  • 例：3♣ 4♣ 5♦ 9♠ J♥ / 6♠ 7♠ 2♦ 9♦ K♣ / 9♠ 9♦ A♣ 4♣ 2♥（ポジション依存）

C — フォールド推奨（EV 低）

説明具体例
3枚交換前提の薄い投機ハンド（完成率低）7♠ 8♦ J♣ 2♥ 3♦（投機的）
ギリギリの9ペア以外の弱いマージナルハイ9♣ 9♥ 4♦ 6♠ 2♣（マージナル、状況依存で捨てる）
  • 例：T♣ J♦ 3♠ 6♥ 8♦ / 5♠ 9♦ Q♣ K♥ 2♣（弱い）
