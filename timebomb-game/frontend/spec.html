1. ゲーム概要

「タイムボム」は、プレイヤーが🚔 時空警察と💣 ボマー団の2陣営に分かれ、導線（ワイヤー）カードをめくることで爆弾の解除を目指す正体隠匿型ボードゲームのオンライン版です。

  • 時空警察：全ての「解除コード（⚡）」カードをめくって爆弾を解除することが目標。
  • ボマー団：「爆弾（💣）」カードをめくらせるか、4ラウンド耐えきることが目標。

3. ゲームルール

3.1 ゲームの流れ

  1. カード配布：全カードをシャッフルし、各プレイヤーに均等配布。自分の手札の種類は自分だけに見える。
  2. ニッパーでカット：現在の「ニッパー保持者」が、自分以外のプレイヤーのカードを1枚選んでめくる。
  3. ニッパーの移動：カードをめくられたプレイヤーが次のニッパー保持者になる。
  4. ラウンド終了：人数分のカードがめくられたら1ラウンド終了。残りカードを回収・シャッフルし、再配布。
  5. 最大4ラウンドまで繰り返す。

4.5 データの秘匿性

  • 他プレイヤーの手札の種類はサーバー側でマスク（type: 'unknown'）して送信
  • 役職も自分のもの以外はマスク
  • ゲーム終了時のみ全情報を開示

4.6 切断・再接続

  • 切断後 30秒間 復旧を待機（ページリロードで再接続可能）
  • 30秒以内に復旧しない → プレイヤーをルームから削除
  • ゲーム中に退出 → game_aborted で全員にゲーム中断を通知
  • ホスト退出 → 次のプレイヤーにホスト権を自動移譲

4.7 ルーム管理

  • ルームコード: 4文字の大文字アルファベット（例: ABCD）
  • データ保存: サーバーメモリ上のみ（永続化なし）

  • Botの手番は 1.2秒後に自動でランダムなカードをカット
  • 1人でもゲームの全進行・勝敗を確認可能

6. 制約・注意事項

⚠️ Render.com 無料プランの制約
• 15分無操作でサーバーがスリープ → 初回接続時に最大60秒のウォームアップ待機
• サーバー再起動でルーム情報が消滅（メモリ上のみのため）
⚠️ ゲーム中の退出
• ゲーム中にプレイヤーが切断・退出するとゲームが強制終了されます
