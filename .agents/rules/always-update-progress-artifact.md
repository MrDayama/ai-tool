# 📜 ルール: 全作業における画面右サイドバー進捗ダッシュボード常時更新ルール

今後、テスト作業に限らず**すべての開発・改修・調整・保守作業**において、以下の手順を**必ず自動的に**実行すること。

1. **画面右サイドバー用の進捗アーティファクト運用**:
   - 作業を開始する際、`implementation_plan.md` アーティファクトを「作業予定 ＆ リアルタイム進捗ダッシュボード」として作成・更新する。
   - `ArtifactMetadata` の `UserFacing: true` および `RequestFeedback: true` を設定し、ユーザー画面右側の Artifact サイドパネル（補助ウィンドウ）に常時固定表示させる。

2. **作業ごとのリアルタイム更新**:
   - コードの編集、機能追加、バグ修正、テスト実行、デザイン調整等の**作業を行うたびに**、即座に `implementation_plan.md` のチェックリストと進捗率 (%) を最新状態へ更新すること。

3. **ダッシュボードの構成**:
   - **総合進捗率 (Progress Bar)**: 全体タスクの達成度
   - **作業予定 ＆ 実施状況テーブル**: 現在実行中のタスク、完了済みタスク、今後の作業予定の一覧
   - **成果物・変更ファイルへの直接リンク**: 修正されたコードファイルやドキュメントへのリンク
