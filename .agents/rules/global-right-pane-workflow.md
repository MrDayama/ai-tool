# 📜 Antigravity グローバルルール: 新規プロジェクト自動右ペイン計画 ＆ サブタスクリアルタイム表示ルール

本ルールは、**今後のすべての新規プロジェクト・ワークスペース**において、ユーザーからの明示的な指示がなくても**自動的に適用**される最優先行動ルールです。

---

## ⚡ 1. 自動右ペイン計画 ＆ タスク展開の義務化 (Auto-Right-Pane Workflow)

1. **指示なしでの自動起動**:
   - 新規プロジェクト開始時および任意の作業時には、右ペイン（Auxiliary Pane）に作業計画 (`implementation_plan.md`) と AIトークン消費量ダッシュボード (`token_dashboard.md`) を別のタブ（独立アーティファクト）として自動作成・表示します。
   - 作業計画タブ (`implementation_plan.md`) と トークン監視タブ (`token_dashboard.md`) は切り離し、別々のタブとして個別にアクセス・確認できるように構成します。
   - `ArtifactMetadata` に `UserFacing: true` および `RequestFeedback: true` を設定し、右側パネルに自動固定表示させること。

2. **計画記載の徹底・超詳細化**:
   - 単なる概要にとどめず、**全体作業の工程、対象ファイル・関数、具体的修正内容、前提条件、検証手順、および潜在リスクをステップバイステップで「超詳細に」網羅して記載**すること。

3. **サブタスク項目ごとの即時リアルタイム更新原則 (Step-by-Step Live Update)**:
   - 全作業が終了した最後の完了時のみに一括更新することを**厳禁**とする。
   - 作業内の細かなサブタスク（Step 1, Step 2, Step 3...）が 1 つ完了・進行するたびに、即座に進捗ドキュメントを書き換え更新し、右ペインにリアルタイムな進捗推移を可視化させること。

4. **全主要 AI モデル別 トークン消費量・残量比較ダッシュボードの常時設置**:
   - 右ペインのアーティファクト上部に、Gemini (3.6 Pro/Flash), Claude (3.5 Sonnet/Opus), OpenAI (o1/o3-mini/GPT-4o), DeepSeek (R1/V3) 等の **最大コンテキスト枠・推定消費量・残容量比較ダッシュボード** を常に設置・更新すること。
