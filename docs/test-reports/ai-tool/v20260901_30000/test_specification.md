# 🧪 ユーザー環境同等テスト仕様書 ＆ 検証計画

ユーザーが実際に本番環境 (GitHub Pages) およびローカルブラウザ環境で利用するフロー（履歴モーダルからのデータ読み込み、リプレイ再生、および各物理アニメーションの連動）を検証するためのテスト仕様書とテスト実行計画です。

---

## 🎯 テストの目的
1. **ユーザー同等環境の再現**: ブラウザ (Chromium) を使用し、本番デプロイ済み URL (`https://mrdayama.github.io/ai-tool/`) およびローカルビルド環境にてユーザー操作と同等のフロー（「📚 履歴一覧」モーダルからのハンドロード・「▶ 再生」ボタン・「⏭ コマ送り」）を実施する。
2. **物理アニメーションの決定的一瞬のビジュアル確認**:
   - 🪙 **SB / BB ブラインド投下アニメーション** (`animateBlindBets`)
   - 🪙 **Fold(降りる)時の個別チップポット吸い込み演出** (`animateSingleSeatGather`)
   - 🪙 **全員のアクション確定・ストリート移行時の一括Pot吸い込み演出** (`animateGatherChips`)
   - 🏆 **勝者 Main Pot 獲得配当・スタック連動ビメラルド光沢演出** (`animateAwardWinner`)
3. **キャプチャ画像の取得と検証**: 各テストケースで実際に動作している瞬間のキャプチャ画像を取得し、ユーザーに提示・確認する。

---

## 🛠 検証自動化スクリプト計画 (`scratch/run_full_user_environment_tests.py`)
Playwright を使用し、実際に本番 Web アプリケーションを開いて上記 TC-01 ～ TC-05 を順番に全自動実行し、アニメーション発火中の決定的一瞬をハイスピードキャプチャ撮影いたします。
